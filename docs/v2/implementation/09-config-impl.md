# 实施指南：09-Config

> 本文档描述配置文件的解析逻辑、默认值处理以及环境变量的覆盖机制。

## 1. 配置结构定义

使用 Zod 定义配置 Schema，确保类型安全。

**依赖**: `zod`

```typescript
// src/config/schema.ts
import { z } from 'zod';

export const ConfigSchema = z.object({
  languages: z.object({
    tier1: z.array(z.string()).default(['typescript', 'javascript', 'python']),
    tier2: z.array(z.string()).default([]),
    tier3: z.array(z.string()).default([]),
  }).default({}),
  
  mode: z.enum(['full_auto', 'hybrid', 'manual_only']).default('hybrid'),
  
  hybrid: z.object({
    project_md: z.object({
      enabled: z.boolean().default(true),
      path: z.string().default('.agentmem/project.md'),
      max_lines: z.number().default(50),
      auto_include: z.boolean().default(true),
    }).default({}),
  }).default({}),
  
  index: z.object({
    ignore: z.array(z.string()).default(['.gitignore', '.augmentignore']),
    maxFileSize: z.string().default('1MB'),
  }).default({}),
  
  chunker: z.object({
    maxChars: z.number().default(1500),
    overlap: z.number().default(200),
  }).default({}),
  
  retrieval: z.object({
    topK: z.number().default(10),
    ask: z.object({
      enabled: z.boolean().default(true),
      provider: z.enum(['openai', 'anthropic', 'custom']).default('openai'),
      model: z.string().default('gpt-4o-mini'),
      apiBaseUrl: z.string().optional(),
      apiKeyEnv: z.string().default('OPENAI_API_KEY'),
    }).default({}),
  }).default({}),
  
  state: z.object({
    export_path: z.string().default('.ccq/state.json'),
    auto_export: z.boolean().default(true),
  }).default({}),
});

export type UserConfig = z.infer<typeof ConfigSchema>;
```

## 2. 配置加载逻辑

### 2.1 优先级
1.  CLI 参数 (最高)
2.  环境变量 (`CCQ_CONFIG_...`)
3.  配置文件 (`.ccq/config.yaml`)
4.  默认值 (最低)

### 2.2 实现细节

```typescript
import { ConfigSchema } from './schema';

export function loadConfig(root: string, cliOptions: any = {}) {
  // 1. Load YAML
  const fileConfig = loadYaml(root);
  
  // 2. Merge with CLI options
  const merged = merge(fileConfig, cliOptions);
  
  // 3. Validate & Fill Defaults
  const result = ConfigSchema.safeParse(merged);
  
  if (!result.success) {
    throw new Error(`Invalid config: ${result.error.message}`);
  }
  
  return result.data;
}
```

## 3. 默认配置生成

`ccq init` 命令将生成默认的 `.ccq/config.yaml` 文件。

```yaml
# Generated by ccq init
mode: hybrid

hybrid:
  project_md:
    enabled: true
    path: .agentmem/project.md

retrieval:
  topK: 10
  ask:
    provider: openai
    model: gpt-4o-mini
```
