# FlowMem Plan - 快速规划

只执行 Phase 1-2（需求澄清 + 详细规划），生成计划但不执行。

## 使用方法

```bash
/flowmem:plan <任务描述>
```

## 上下文

- 要规划的任务：$ARGUMENTS
- 只做规划，不执行代码修改
- 输出：`.agentmem/request.md` + `.agentmem/todolist.md`

## 你的角色

你是**规划师**，负责需求澄清和任务分解，用中文协助用户。

---

## 执行流程

**任务描述**：$ARGUMENTS

### 🔍 Step 1：需求澄清

1. **上下文检索**：理解项目结构和现有代码
2. **需求完整性评分**（0-10 分）：
   - ≥7 分：继续 | <7 分：提出补充问题
3. **方案设计**：设计技术方案
4. **用户确认**：等待用户确认方案

**输出**：`.agentmem/request.md`

### 📋 Step 2：任务分解

1. **WBS 分解**：将方案分解为可执行任务
2. **依赖识别**：识别任务间依赖
3. **工作量估算**：估算每个任务工作量
4. **用户确认**：等待用户确认计划

**输出**：使用 `flowmem todo add` 创建任务

---

## 完成后

规划完成后，用户可以：
- 执行 `/flowmem:execute` 开始执行
- 手动调整 `.agentmem/todolist.md` 中的任务
- 使用 `flowmem todo list` 查看任务列表
