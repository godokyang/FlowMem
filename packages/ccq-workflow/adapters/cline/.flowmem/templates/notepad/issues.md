# 阻塞与问题记录

> 记录实施过程中遇到的阻塞和问题

## 格式

```
[YYYY-MM-DD HH:MM] 问题: <问题描述>
- 状态: 待解决 / 已解决 / 已绕过
- 影响: <对进度的影响>
- 解决方案: <如何解决>
```
